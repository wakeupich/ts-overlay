# TS Overlay 1.1.0

Обновление с аватарами, значками серверных групп, глобальными горячими клавишами,
проверкой обновлений и установщиком.

## Что нового

- **Аватары.** У каждого участника — цветной кружок с инициалами; цвет стабилен и не меняется
  между запусками. Включается/выключается в настройках.
- **Значки серверных групп.** До двух плашек с названиями групп рядом с ником (TS3: имена групп
  читаются через `servergrouplist`). Названия групп видны в подсказке.
- **Глобальные горячие клавиши.**
  - `Ctrl+Alt+O` — показать/скрыть оверлей поверх активного окна (не только в игре).
  - `Ctrl+Alt+H` — «кто говорит» на 6 секунд поверх любого окна.
  - Комбинации меняются в настройках; занятая комбинация вызывает уведомление.
- **Проверка обновлений** через GitHub Releases: при запуске (можно отключить) и вручную
  из меню трея. Если доступен MSI-ассет, оверлей предложит скачать и установить его.
- **Установщик MSI.** Ставится в `%LOCALAPPDATA%\Programs\TSOverlay` без прав администратора,
  создаёт ярлыки в меню «Пуск» и на рабочем столе, корректно удаляется через «Установленные приложения».

## Установка

1. Скачайте `TsOverlay-1.1.0-Setup.msi` и запустите — установка per-user, UAC не потребуется.
2. Либо портативно: `TsOverlay.exe` (нужен .NET 8 Desktop Runtime) или распакованный
   `TsOverlay-1.1.0-win-x64-standalone.zip`.
3. При первом запуске откроются настройки: добавьте игры на вкладке «Игры».

SmartScreen: файлы не подписаны — «Подробнее» → «Выполнить всё равно».

## Обновление с 1.0.0

Настройки и ключи API сохраняются в `%APPDATA%\TsOverlay\config.json` и не затрагиваются.
Достаточно установить 1.1.0 поверх — или распаковать портативную версию.

## Ограничения

- Эксклюзивный полноэкранный режим не поддерживается (только windowed/borderless).
- Картинки аватаров и иконок групп через API клиентов недоступны: ClientQuery не отдаёт файлы,
  TS6 не присылает URL/иконки. Поэтому аватар — инициалы, значок группы — плашка с названием.
- Автопроверка обновлений работает только когда репозиторий публичный (приватный GitHub API
  отдаёт 404). Ручная проверка в этом случае честно сообщает о недоступности.

## Проверено

- TS3: аватары (хэши), группы `Server Admin/Боец/Help`, горячие клавиши, HUD поверх браузера.
- TS6: данные канала, talk/mute, авто-переключение клиентов.
- MSI: установка `/qn` → файлы и ярлыки на месте; удаление → чисто.
