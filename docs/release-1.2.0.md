# TS Overlay 1.2.0

Живой предпросмотр, нормальная высота строк при крупном шрифте и подсказка про перетаскивание.

## Исправлено

- **Предпросмотр снова живой.** Изменения ширины, высоты строки, шрифта, шапки, аватаров,
  значков групп, цветов и положения сразу применяются к оверлею. Раньше обновлялись только
  прозрачность, масштаб и палитра.
- Кнопка «Предпросмотр на рабочем столе» из настроек убрана — предпросмотр включается сам
  при заходе на вкладку «Оверлей» и обновляется на лету.
- **Строки больше не наезжают друг на друга** при увеличении шрифта: высота строки
  автоматически не меньше текста (`max(высота строки, шрифт × 1.55 + 2)`), шапка тоже
  растёт под шрифт. Панель пересчитывает высоту.
- В меню трея убран комментарий в скобках: пункт называется просто **«Поверх любых окон»**.

## Подсказка про перетаскивание

- В настройках на вкладке «Оверлей»: «Перетащить оверлей: зажмите Ctrl+Alt и потяните мышью —
  позиция сохранится».
- В меню трея добавлена строка «Перетащить: Ctrl+Alt + мышь».

## Установка и обновление

- Трей → «Проверить обновления» → 1.2.0 (после установки оверлей запустится сам).
- Или вручную: `TsOverlay-1.2.0-Setup.msi`.

## Файлы

| Файл | Описание |
|---|---|
| `TsOverlay-1.2.0-Setup.msi` | установщик per-user, нужен .NET 8 Desktop Runtime |
| `TsOverlay.exe` | портативная версия, нужен .NET 8 Desktop Runtime |
| `TsOverlay-1.2.0-win-x64-standalone.zip` | самодостаточная сборка без зависимостей |
| `SHA256SUMS.txt` | контрольные суммы |

Сборку и публикацию выполняет GitHub Actions по тегу `v1.2.0`.

## Проверено

- Смена шрифта 14 → 19 при высоте строки 26: панель выросла, текст не обрезается.
- Включение шапки сразу увеличило панель, предпросмотр обновился без сохранения.
- Подсказка о Ctrl+Alt видна на вкладке «Оверлей»; кнопки предпросмотра больше нет.
