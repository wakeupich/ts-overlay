# TS Overlay 1.2.9

Активная вкладка TS6 теперь переключается по self-событиям, а не по эвристикам.
Плюс версия приложения на виду.

## Переключение серверов TS6

- Активное подключение определяется по событиям **своего клиента**: `clientSelfPropertyUpdated`
  (мьют, разговор, `inputHardware`), self `talkStatusChanged` / `clientUpdated` /
  `clientMoved` / `clientEnterView` с другим `connectionId`.
- Повторный `auth` на том же сокете TS6 **игнорирует** (проверено по логу: запросы уходили,
  ответов не было) — поэтому переключение идёт через короткое переподключение
  с запомненным `connectionId`: пауза ~0.3 с вместо 5 с.
- Никакого скоринга и штрафов QUERY — только реальные сигналы клиента.

## Версия приложения

- Заголовок настроек: `TS Overlay — настройки · v1.2.9`.
- Меню трея: строка `Версия 1.2.9`; подсказка иконки — `TS Overlay 1.2.9`.
- Лог: `TS Overlay 1.2.9 запущен`.

## Из 1.2.6–1.2.8

- Автоповтор авторизации, если TS6 ещё не отдал подключения.
- Вопрос «Сохранить изменения?» при закрытии настроек крестиком.
- `clientLeft`/`clientDisconnected` применяются сразу.

## Установка и обновление

- Трей → «Проверить обновления» → 1.2.9 (после установки оверлей запустится сам).
- Или вручную: `TsOverlay-1.2.9-Setup.msi`.
