# TS Overlay 1.1.6

Убраны ложные уведомления «разрешите приложение», которые появлялись при временном падении
сервера TeamSpeak, и уточнено поведение режима «всегда поверх».

## Исправлено

- Уведомление о разрешении Remote Apps теперь показывается **только при явном отказе**
  авторизации (клиент вернул ошибку), а не при каждом обрыве связи или переподключении.
  Раньше после успешной авторизации любой обрыв трактовался как «приложение не разрешено».
- Повторные напоминания — не чаще раза в 10 минут (было 2 минуты и дополнительный таймер на 6 с,
  из-за которого всплывало два уведомления подряд).
- События `neededPermissions` / `clientNeededPermissions` больше не логируются как
  «необработанные»: это штатный запрос прав, а не ошибка.
- Переподключение после обрыва — с паузой 5 с (было 3 с), чтобы не устраивать шторм
  запросов авторизации при недоступном сервере.

## Про «показывает без игры»

Это был включённый режим **«Поверх любых окон (всегда)»**. Он выключен по умолчанию;
галочка — в настройках (Общие → Отображение) и в меню трея. Когда она снята, оверлей
появляется только поверх игр из вкладки «Игры» и скрывается, когда игра не активна.

## Установка и обновление

- С 1.1.0–1.1.5: трей → «Проверить обновления» → 1.1.6. После установки оверлей запускается сам.
- Или вручную: `TsOverlay-1.1.6-Setup.msi`.

## Файлы

| Файл | Описание |
|---|---|
| `TsOverlay-1.1.6-Setup.msi` | установщик per-user, нужен .NET 8 Desktop Runtime |
| `TsOverlay.exe` | портативная версия, нужен .NET 8 Desktop Runtime |
| `TsOverlay-1.1.6-win-x64-standalone.zip` | самодостаточная сборка без зависимостей |
| `SHA256SUMS.txt` | контрольные суммы |

Сборку и публикацию выполняет GitHub Actions по тегу `v1.1.6`.

## Проверено

- Сборка без ошибок; при `AlwaysShowOverlay=false` оверлей скрывается, когда активное окно не игра.
- Логика уведомлений: обрыв после успешной авторизации больше не вызывает `UserNotice`.
