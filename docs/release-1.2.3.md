# TS Overlay 1.2.3

Иконки выключенного микрофона и динамика стали крупнее и теперь масштабируются вместе
с высотой строки.

## Что изменилось

- Базовый размер иконок `микрофон/звук выключен` — 13 → **18 px** (при стандартной строке 26 px).
- Размер привязан к строке: `IconSize = clamp(RowHeight × 0.7, 16, 30)`, поэтому при крупном
  шрифте и высокой строке иконки тоже увеличиваются, а не выглядят точкой.
- Немного увеличены отступы между иконками.

## Установка и обновление

- Трей → «Проверить обновления» → 1.2.3 (после установки оверлей запустится сам).
- Или вручную: `TsOverlay-1.2.3-Setup.msi`.

## Файлы

| Файл | Описание |
|---|---|
| `TsOverlay-1.2.3-Setup.msi` | установщик per-user, нужен .NET 8 Desktop Runtime |
| `TsOverlay.exe` | портативная версия, нужен .NET 8 Desktop Runtime |
| `TsOverlay-1.2.3-win-x64-standalone.zip` | самодостаточная сборка без зависимостей |
| `SHA256SUMS.txt` | контрольные суммы |

Сборку и публикацию выполняет GitHub Actions по тегу `v1.2.3`.

## Проверено

- Сборка без ошибок; размер иконок берётся из `ClientRow.IconSize` (Binding в стиле `MuteIcon`).
