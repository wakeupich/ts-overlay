# TS Overlay 1.0.0

Первый релиз игрового оверлея TeamSpeak: показывает состав текущего канала, подсвечивает
говорящих и помечает тех, у кого выключен микрофон или звук. Работает с **TeamSpeak 3**
и **TeamSpeak 6**, живёт в трее и появляется только поверх выбранных игр.

## Что умеет

- Список всех участников вашего канала: ник, «говорит», микрофон выключен, звук выключен, отошёл.
- Подсветка говорящего: цвет строки, точка и ник.
- Tray-иконка: включить/выключить оверлей, настройки, предпросмотр, запуск TeamSpeak, выход.
- Автозапуск с Windows; опция запускать клиент TeamSpeak вместе с оверлеем.
- Список игр: оверлей показывается только когда активна игра из списка.
- Настройка положения (8 позиций), отступов, ширины, масштаба, прозрачности, цветов и шрифта.
- Конфиг в `%APPDATA%\TsOverlay\config.json`, ключи API шифруются DPAPI.
- Диагностика: `TsOverlay.exe --probe ts3|ts6`, `TsOverlay.exe --settings`.

## Установка

1. Скачайте `TsOverlay.exe` из этого релиза.
2. Установите [.NET 8 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0) (x64), если его ещё нет.
3. Запустите `TsOverlay.exe`. Файл не подписан, поэтому SmartScreen может предупредить:
   «Подробнее» → «Выполнить всё равно».
4. В трее откройте настройки и добавьте игры: вкладка «Игры» → «Добавить из запущенных…».

Файл `TsOverlay-1.0.0-win-x64-standalone.zip` не требует установленного .NET —
внутри самодостаточная сборка (тяжелее, зато запускается сразу).

## Настройка клиентов

**TeamSpeak 3.** В клиенте должен быть включён плагин ClientQuery (Настройки → Плагины).
Ключ API оверлей обычно читает сам из `%APPDATA%\TS3Client\clientquery.ini`; если нет —
вкладка «Подключение» → «Взять из ini».

**TeamSpeak 6.** При первом подключении клиент показывает запрос доступа — разрешите
приложение «TS Overlay» (Настройки → Remote Apps). Ключ сохраняется, повторно спрашивать не будет.

## Требования

- Windows 10/11 x64.
- TeamSpeak 3 (3.6.x) и/или TeamSpeak 6.
- .NET 8 Desktop Runtime — для облегчённой сборки.

## Известные ограничения

- Не работает в **эксклюзивном полноэкранном** режиме: обычное окно не рисуется поверх него.
  Оконный и безрамочный полноэкранный режимы поддерживаются.
- Remote Apps в TS6 — API в статусе alpha; имена событий могут меняться между версиями клиента.
- Оверлей не подписан цифровой подписью (SmartScreen может ругаться).

## Проверено

- TeamSpeak 3: канал, участники, `input muted`, события «начал/закончил говорить».
- TeamSpeak 6: авторизация Remote Apps, сервер и канал, два клиента в канале, talk/mute-события.
- Отрисовка поверх окна на 225 % DPI (Windows 11).
