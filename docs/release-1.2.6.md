# TS Overlay 1.2.6

Исправления по утреннему запуску TS6 с двумя серверами и по сохранению настроек.

## TS6: автоподключение и выбор сервера

- Если в ответе `auth` ещё нет подключений (TS6 только стартует) — оверлей больше не зависает
  в состоянии «нет подключения», а сам повторяет авторизацию через несколько секунд.
  Раньше в этом случае помогал только пункт «Переподключиться».
- Если подключений несколько, выбирается **реальное**, а не query/пустое: у кандидата
  должен быть свой клиент, клиент-QUERY штрафуется, предпочтение — подключению с большим
  числом клиентов. В логе: `TS6: подключения [1,2], выбрано 2`.
- Активное подключение по-прежнему уточняется событием `inputHardware`; при переключении
  серверов выполняется один ресинк.

## Настройки

- При закрытии окна настроек крестиком, если были изменения, появляется вопрос
  **«Сохранить изменения перед закрытием?»** (Да / Нет / Отмена).
  Раньше крестик молча откатывал всё к сохранённому состоянию — отсюда «настройки не сохранились».
- «Отмена» по-прежнему закрывает без сохранения, «Сохранить» — сохраняет.
- Запись конфига атомарная (tmp + move) — уже была, менять не пришлось.

## Установка и обновление

- Трей → «Проверить обновления» → 1.2.6 (после установки оверлей запустится сам).
- Или вручную: `TsOverlay-1.2.6-Setup.msi`.
