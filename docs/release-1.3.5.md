# TS Overlay 1.3.5

Исправлено устаревание списка канала: после перемещения в другой канал оверлей мог
показывать старый состав.

## Причина

Если активное подключение TS6 менялось без события `inputHardware`, события
`clientMoved`/`clientEnterView` от **своего** клиента с другим `connectionId` отбрасывались.
В результате оверлей оставался на старом канале — там был другой список людей.

## Что исправлено

- `clientMoved` и `clientEnterView` для своего клиента с другого подключения теперь
  переключают активный сервер (короткий ресинк) — список канала подтягивается сразу.
- Остальные события неактивных подключений по-прежнему игнорируются.
- Активный сервер по-прежнему определяется по `inputHardware=true` своего клиента
  и фактической речи.

## Проверено

- `--probe ts6` показывает актуальный канал «Тени ужаса» и 5 человек; оверлей после
  перезапуска показывает тот же состав.
- Сборка 1.3.5 без ошибок.

## Установка и обновление

- Трей → «Проверить обновления» → 1.3.5 (после установки оверлей запустится сам).
- Или вручную: `TsOverlay-1.3.5-Setup.msi`.
