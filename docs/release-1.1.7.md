# TS Overlay 1.1.7

Уточнён режим «поверх любых окон»: теперь он работает только пока запущена игра из списка,
а не постоянно.

## Что изменилось

- Галочка **«Поверх любых окон, пока запущена игра»** (настройки → Общие → Отображение,
  и в трее). Если игра запущена — оверлей висит поверх любых окон, даже когда ты свернул игру.
  Если игра не запущена — оверлей скрыт.
- Проверка запущенной игры идёт по процессам из списка «Игры» (не по активному окну),
  раз в 3 секунды; при старте/остановке игры оверлей появляется/исчезает сам.
- Пункт «Своя позиция (перетаскиванием)» и сохранение координат из 1.1.5 сохранены.

## Из 1.1.6

- Уведомления «разрешите приложение» больше не выскакивают при временном падении сервера TS:
  только при явном отказе авторизации, не чаще раза в 10 минут.
- `neededPermissions` / `clientNeededPermissions` не считаются ошибкой.

## Установка и обновление

- Трей → «Проверить обновления» → 1.1.7 (после установки оверлей запустится сам).
- Или вручную: `TsOverlay-1.1.7-Setup.msi`.

## Файлы

| Файл | Описание |
|---|---|
| `TsOverlay-1.1.7-Setup.msi` | установщик per-user, нужен .NET 8 Desktop Runtime |
| `TsOverlay.exe` | портативная версия, нужен .NET 8 Desktop Runtime |
| `TsOverlay-1.1.7-win-x64-standalone.zip` | самодостаточная сборка без зависимостей |
| `SHA256SUMS.txt` | контрольные суммы |

Сборку и публикацию выполняет GitHub Actions по тегу `v1.1.7`.

## Проверено

- Сборка без ошибок; режим выключен по умолчанию, при выключенной игре оверлей скрывается
  (проверка `AnyGameRunning` по процессам списка игр).
