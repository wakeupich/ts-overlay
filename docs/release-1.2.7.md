# TS Overlay 1.2.7

Активная вкладка сервера в TS6 определяется по событиям твоего клиента, без эвристик.
Переключение — повторным `auth` на том же сокете, без пятисекундного переподключения.

## Как определяется активный сервер

- Любое `clientSelfPropertyUpdated` (мьют, разговор, `inputHardware`) приходит от активной
  вкладки. Если `connectionId` отличается от текущего — оверлей переключается на него.
- То же для self-событий `talkStatusChanged`, `clientUpdated`, `clientMoved`, `clientEnterView`:
  они сверяются с `clientId` своего клиента для каждого подключения (из ответа `auth`).
- Никакого «кто больше/меньше» и штрафов QUERY больше нет.

## Скорость переключения

При смене вкладки не рвётся WebSocket: на том же соединении повторно отправляется `auth`,
ответ выбирает запомненное подключение и сразу обновляет снимок. Это миллисекунды, а не 5 секунд.

## Автозапуск TS6

Если в ответе `auth` ещё нет подключений (клиент только стартует), оверлей сам повторяет
попытку, без ручного «Переподключиться» (из 1.2.6).

## Настройки

Сохранены изменения 1.2.6: при закрытии окна крестиком с несохранёнными изменениями
появляется вопрос «Сохранить изменения?».

## Установка и обновление

- Трей → «Проверить обновления» → 1.2.7 (после установки оверлей запустится сам).
- Или вручную: `TsOverlay-1.2.7-Setup.msi`.
