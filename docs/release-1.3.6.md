# TS Overlay 1.3.6

Исправлено устаревание списка канала после перехода в другой канал.

## Что показал лог

TS6 **не присылает** отдельное событие «я перешёл в канал»: в трассировке нет
`clientMoved`/`clientEnterView` для своего `clientId` при смене канала. Вместо этого при
подписке на новый канал приходят `clientMoved`/`clientEnterView` для его участников
с `newChannelId` нового канала.

Старый код обновлял текущий канал только если событие было про **своего** клиента, поэтому
`CurrentChannelId` оставался от прошлого канала, и фильтр показывал старый список людей.

## Что исправлено

- `clientEnterView` обновляет текущий канал на канал вошедшего клиента — это канал, на который
  подписан просмотр.
- `clientMoved` с `oldChannelId=0` (клиент появился в просмотре) тоже обновляет текущий канал.
- Своего клиента при перемещении по-прежнему обновляем напрямую.
- Список в оверлее теперь соответствует каналу, который открыт в TS6.

## Установка и обновление

- Трей → «Проверить обновления» → 1.3.6 (после установки оверлей запустится сам).
- Или вручную: `TsOverlay-1.3.6-Setup.msi`.
