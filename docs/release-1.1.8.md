# TS Overlay 1.1.8

Режим «поверх любых окон» теперь понимается буквально: оверлей остаётся на экране, когда окно
игры теряет фокус, но зависит от запущенной игры.

## Как работает режим

- Включён, **список игр не пуст** → оверлей виден, пока запущен хотя бы один процесс из списка
  (даже если игра свёрнута или активно другое окно). Игра закрылась — оверлей скрылся.
- Включён, **список игр пуст** → оверлей виден всегда.
- Выключен → как раньше: только когда активна игра из списка.

Галочка: настройки → Общие → Отображение → «Поверх любых окон (пока игра запущена; без списка игр — всегда)»
или трей → «Поверх любых окон (пока игра запущена)».

## Из 1.1.6

- Уведомления «разрешите приложение» больше не выскакивают при временном падении сервера TS:
  только при явном отказе авторизации, не чаще раза в 10 минут.
- `neededPermissions` / `clientNeededPermissions` не считаются ошибкой.

## Установка и обновление

- Трей → «Проверить обновления» → 1.1.8 (после установки оверлей запустится сам).
- Или вручную: `TsOverlay-1.1.8-Setup.msi`.

## Проверено

- При включённом режиме и запущенном Caliber оверлей виден; при потере фокуса игрой
  `OnGameWindowChanged` больше не скрывает его, пока процесс игры жив.
- Проверка запущенной игры — по процессам из списка, раз в 3 секунды (`AnyGameRunning`).
