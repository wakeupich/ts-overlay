# TS Overlay 1.2.8

Версия приложения теперь видна в интерфейсе.

## Где смотреть версию

- **Заголовок окна настроек**: `TS Overlay — настройки · v1.2.8`.
- **Меню трея**: отдельная строка `Версия 1.2.8` под статусом подключения.
- **Подсказка при наведении на иконку в трее**: `TS Overlay 1.2.8`.
- **Лог** `%APPDATA%\TsOverlay\overlay.log`: строка `TS Overlay 1.2.8 запущен`.

## Из 1.2.7

- Активная вкладка TS6 определяется по self-событиям клиента (мьют, разговор, inputHardware,
  self talk/update/move/enter), без эвристик и скоринга.
- Переключение серверов — повторный `auth` на том же сокете, без 5-секундного реконнекта.

## Установка и обновление

- Трей → «Проверить обновления» → 1.2.8 (после установки оверлей запустится сам).
- Или вручную: `TsOverlay-1.2.8-Setup.msi`.

## Файлы

| Файл | Описание |
|---|---|
| `TsOverlay-1.2.8-Setup.msi` | установщик per-user, нужен .NET 8 Desktop Runtime |
| `TsOverlay.exe` | портативная версия, нужен .NET 8 Desktop Runtime |
| `TsOverlay-1.2.8-win-x64-standalone.zip` | самодостаточная сборка без зависимостей |
| `SHA256SUMS.txt` | контрольные суммы |

Сборку и публикацию выполняет GitHub Actions по тегу `v1.2.8`.
