# TS Overlay 1.2.4

Исправлена кнопка «Отмена» в настройках.

## Причина

У кнопки стоял только `IsCancel="True"` — в WPF это свойство реагирует на клавишу **Esc**,
но не на клик мышью. Клик уходил в никуда, окно не закрывалось.

## Что исправлено

- Добавлен обработчик `OnCancel` → `Close()`.
- При закрытии без сохранения вызывается `_restore()`: предпросмотр откатывается
  к сохранённому конфигу, оверлей возвращается в обычный режим.
- «Отмена» не завершает приложение — закрывает только окно настроек (как и ожидается).

## Установка и обновление

- Трей → «Проверить обновления» → 1.2.4 (после установки оверлей запустится сам).
- Или вручную: `TsOverlay-1.2.4-Setup.msi`.
