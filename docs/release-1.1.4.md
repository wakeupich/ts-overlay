# TS Overlay 1.1.4

Исправление «оверлей пропал после обновления»: теперь установщик не только закрывает старую
версию, но и сам поднимает новую.

## Что исправлено

- После автообновления (трей → «Проверить обновления» → скачать MSI) оверлей запускается снова
  автоматически. Раньше приложение закрывалось для замены файлов и оставалось закрытым —
  со стороны это выглядело как «оверлей пропал».
- Установщик запускается цепочкой `msiexec /i ... /qb`, ждёт завершения и стартует
  `%LOCALAPPDATA%\Programs\TSOverlay\TsOverlay.exe`.

## Что было в 1.1.3

- Не подсвечивать «говорит», если у клиента выключен микрофон (`status=2`, `inputMuted`,
  `inputDeactivated`, серверный `isMuted`).
- Иконка приложения, перетаскивание `Ctrl+Alt`+мышь, прозрачность только фона, закреплённый
  предпросмотр настроек.

## Установка и обновление

- С 1.1.0–1.1.3: трей → «Проверить обновления» → 1.1.4 (после установки оверлей вернётся сам).
- Или вручную: `TsOverlay-1.1.4-Setup.msi`, per-user, без UAC.

## Файлы

| Файл | Описание |
|---|---|
| `TsOverlay-1.1.4-Setup.msi` | установщик per-user, нужен .NET 8 Desktop Runtime |
| `TsOverlay.exe` | портативная версия, нужен .NET 8 Desktop Runtime |
| `TsOverlay-1.1.4-win-x64-standalone.zip` | самодостаточная сборка без зависимостей |
| `SHA256SUMS.txt` | контрольные суммы |

Сборку и публикацию выполняет GitHub Actions по тегу `v1.1.4`.

## Проверено

- Перезапуск после MSI: цепочка `cmd /c msiexec ... & start ...` проверена на релизном MSI 1.1.3→1.1.4.
- Падений в журнале событий Windows нет; прежние исчезновения были из-за ручных `Stop-Process`
  и удаления приложения при тестах деинсталлятора.
