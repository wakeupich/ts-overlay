# TS Overlay 1.1.5

Два изменения: режим «поверх любых окон» и исправление сохранения позиции при перетаскивании
во время открытых настроек.

## Новое

- **Галочка «Показывать поверх любых окон (всегда)»** в настройках (вкладка «Общие» → «Отображение»)
  и в меню трея. Оверлей висит на экране постоянно, независимо от того, какая игра активна,
  как `Ctrl+Alt+H`, только без таймера. Позиция — обычная (угол/своя), не прыгает за окнами.
- В списке «Угол экрана» появился пункт **«Своя позиция (перетаскиванием)»**.

## Исправлено

- Перетаскивание при открытых настройках больше не сбрасывается кнопкой «Сохранить»:
  окно настроек работало со своей копией конфига, и `Save` перезаписывал `Custom` старыми
  значениями. Теперь при перетаскивании копия синхронизируется (`SyncCustomPosition`),
  в списке выбирается «Своя позиция», и сохранение оставляет новые координаты.
- После закрытия настроек оверлей возвращается в прежний режим, а не остаётся в предпросмотре.

## Установка и обновление

- С 1.1.0–1.1.4: трей → «Проверить обновления» → 1.1.5. После установки оверлей запускается сам.
- Или вручную: `TsOverlay-1.1.5-Setup.msi`.

## Файлы

| Файл | Описание |
|---|---|
| `TsOverlay-1.1.5-Setup.msi` | установщик per-user, нужен .NET 8 Desktop Runtime |
| `TsOverlay.exe` | портативная версия, нужен .NET 8 Desktop Runtime |
| `TsOverlay-1.1.5-win-x64-standalone.zip` | самодостаточная сборка без зависимостей |
| `SHA256SUMS.txt` | контрольные суммы |

Сборку и публикацию выполняет GitHub Actions по тегу `v1.1.5`.

## Проверено

- Режим «всегда поверх»: при включённом флаге окно оверлея видимо и остаётся на месте
  при смене активного окна (guard в `OnGameWindowChanged`).
- Сборка 1.1.5: `dotnet build` без ошибок; MSI устанавливается поверх 1.1.4.
