# TS Overlay 1.1.2

Срочное исправление: в 1.1.1 окно настроек падало с `XamlParseException` — иконка окна
искалась как `views/app.ico` вместо ресурса приложения. Скачивайте 1.1.2, версию 1.1.1 пропустите.

## Что исправлено

- `Icon="app.ico"` в `SettingsWindow.xaml` и `RunningAppsWindow.xaml` заменён на
  `pack://application:,,,/app.ico`. Настройки и выбор игр открываются нормально, иконка в заголовке есть.
- Иконка приложения из 1.1.1 сохранена: exe, окна, трей, ярлыки, установщик и «Установленные приложения».

## Всё из 1.1.1

- **Перетаскивание оверлея**: зажмите `Ctrl+Alt`, потяните мышью; позиция сохраняется
  (`Anchor=Custom` + смещение) и восстанавливается поверх игры.
- **Прозрачность только фона** слайдером 20–100 %: текст, иконки, аватары и значки групп
  остаются непрозрачными; изменения сразу видны в предпросмотре.
- **Настройки не дёргают оверлей**: пока окно открыто, оверлей закреплён, не перескакивает
  на игру и не прячется при обновлении канала. После закрытия возвращается прежний режим.
- Аватары-инициалы, плашки серверных групп (TS3), глобальные хоткеи `Ctrl+Alt+O` / `Ctrl+Alt+H`,
  проверка обновлений, MSI-установщик per-user.

## Установка и обновление

- `TsOverlay-1.1.2-Setup.msi` — per-user, без UAC, ставит в `%LOCALAPPDATA%\Programs\TSOverlay`.
- Либо портативно: `TsOverlay.exe` (нужен .NET 8 Desktop Runtime) или
  `TsOverlay-1.1.2-win-x64-standalone.zip` (без зависимостей).
- С 1.1.0/1.1.1: трей → «Проверить обновления» → 1.1.2. Настройки и ключи API сохраняются.
