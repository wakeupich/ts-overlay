# TS Overlay 1.3.7

Откат ошибочного определения текущего канала из 1.3.6.

## Причина

В 1.3.6 текущий канал обновлялся по `clientEnterView`/`clientMoved` **любого** клиента.
TS6 присылает такие события и при подписке на просмотр каналов, поэтому текущим мог стать
пустой канал — оверлей писал «В канале никого», хотя в реальном канале были люди.

## Что исправлено

- Текущий канал снова обновляется только по событиям **своего** клиента
  (`clientMoved`/`clientEnterView` с собственным `clientId`).
- Список снова фильтруется по каналу из авторизации/своего перемещения.

## Установка и обновление

- Трей → «Проверить обновления» → 1.3.7 (после установки оверлей запустится сам).
- Или вручную: `TsOverlay-1.3.7-Setup.msi`.
