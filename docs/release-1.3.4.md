# TS Overlay 1.3.4

Устранение обрезания нижней строки оверлея при различных масштабах и настройках шрифта, динамическое измерение размера контента панели, оптимизация вкладки «Общие» без вертикального скроллбара.

## Что изменилось

- **Оверлей — устранение обрезания снизу**: исправлена ошибка расчета высоты панели при пользовательских масштабах (0.8–0.9), включенных аватарах и значках микрофона/звука. В формулу расчета высоты включены толщина рамки панели, межстрочные отступы и субпиксельный запас.
- **Динамический замер высоты через WPF Layout**: в `RefreshLayout` теперь выполняется проход измерения реального размера дерева элементов панели (`RootBorder.Measure`), благодаря чему размер Win32-окна всегда точно соответствует содержимому и ни при каких условиях не срезает нижнюю строку участников.
- **Синхронизация при смене настроек**: при изменении масштаба или состава канала размер и позиция окна в игре немедленно актуализируются через Win32 API (`SetWindowPos`).
- **Окно настроек — вкладка «Общие»**: устранено появление вертикального скроллбара. Настройки языка интерфейса и режима клиента TeamSpeak объединены в компактный общий блок, оптимизированы вертикальные отступы и увеличен базовый размер окна настроек.

## Установка и обновление

- Трей → «Проверить обновления» → 1.3.4 (после установки оверлей перезапустится автоматически).
- Или вручную: `TsOverlay-1.3.4-Setup.msi`.
