# TS Overlay 1.3.1

Оставлен только бейдж AFK — без сообщения об отсутствии и подсказки.

## Что изменилось

- В строке участника по-прежнему оранжевый бейдж **AFK**, если человек отошёл.
- Убраны tooltip и текст сообщения об отсутствии — они только загромождали строку
  (к тому же оверлей click-through, и подсказка могла вообще не появляться).
- Ник отошедшего по-прежнему приглушается.

## Установка и обновление

- Трей → «Проверить обновления» → 1.3.1 (после установки оверлей запустится сам).
- Или вручную: `TsOverlay-1.3.1-Setup.msi`.

## Файлы

| Файл | Описание |
|---|---|
| `TsOverlay-1.3.1-Setup.msi` | установщик per-user, нужен .NET 8 Desktop Runtime |
| `TsOverlay.exe` | портативная версия, нужен .NET 8 Desktop Runtime |
| `TsOverlay-1.3.1-win-x64-standalone.zip` | самодостаточная сборка без зависимостей |
| `SHA256SUMS.txt` | контрольные суммы |

Сборку и публикацию выполняет GitHub Actions по тегу `v1.3.1`.
