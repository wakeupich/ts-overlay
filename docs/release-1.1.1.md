# TS Overlay 1.1.1

Исправления по итогам первых дней использования: иконка приложения, перетаскивание оверлея,
прозрачность только фона и стабильный предпросмотр в настройках.

## Что нового

- **Иконка приложения.** Добавлена в exe, окна настроек, окно выбора игр, ярлыки «Пуск»/рабочий стол
  и в установщик (иконка в «Установленные приложения»).
- **Перетаскивание мышью.** Зажмите `Ctrl+Alt` — оверлей становится интерактивным (синяя рамка,
  курсор «перемещение»), потяните мышью, отпустите. Позиция сохраняется как `Anchor=Custom`
  и восстанавливается при следующих запусках, в том числе поверх игры.
- **Прозрачность фона слайдером.** Ползунок 20–100 % меняет только подложку панели; текст, иконки,
  аватары и значки групп остаются полностью непрозрачными. Изменения видны сразу в предпросмотре.
- **Настройки больше не «дёргают» оверлей.** Пока окно настроек открыто, оверлей всегда виден
  на рабочем столе, не перескакивает на игру и не прячется при обновлении состава канала.
  После закрытия настроек возвращается прежний режим (игра/рабочий стол).
- Исправлена Capitalization инициалов аватара для ников без пробелов (`ok` → `OK`).

## Установка

`TsOverlay-1.1.1-Setup.msi` — per-user, без UAC, ставит в `%LOCALAPPDATA%\Programs\TSOverlay`,
ярлыки с иконкой. Либо портативно: `TsOverlay.exe` (нужен .NET 8 Desktop Runtime) или
`TsOverlay-1.1.1-win-x64-standalone.zip` (без зависимостей).

## Обновление с 1.1.0

Настройки и ключи API в `%APPDATA%\TsOverlay\config.json` сохраняются. Можно установить поверх
или проверить обновление из трея: «Проверить обновления» — оверлей 1.1.0 предложит скачать
и поставить MSI автоматически (с 1.1.0 проверка уже работает, репозиторий публичный).

## Ограничения

- Эксклюзивный полноэкранный режим не поддерживается; в borderless/windowed перетаскивание
  и оверлей работают.
- Картинки аватаров и иконок групп API клиентов не отдают — аватар рисуется инициалами,
  группа показывается текстовой плашкой.

## Проверено

- Перетаскивание: `Ctrl+Alt` + drag, сохранение `CustomOffset`, позиция восстановлена.
- Прозрачность 35 %: фон полупрозрачный, текст/иконки непрозрачные (скриншот поверх Caliber).
- Иконка извлекается из exe, MSI ставится/удаляется (`/qn`), версия 1.1.1 в «Установленных приложениях».
- Предпросмотр в настройках не перехватывается игрой (guard по `_settingsOpen`).
