# TS Overlay 1.2.1

Исправление: события TeamSpeak больше не сбрасывают настройки, которые ты меняешь
в предпросмотре.

## Причина

Пока окно настроек открыто, каждый `OnSnapshot` (кто-то заговорил, выключил микрофон,
зашёл в канал) перерисовывал оверлей **сохранённым** конфигом, а не текущим предпросмотром.
Из-за этого изменения откатывались к состоянию «до входа в настройки».

## Что исправлено

- При открытых настройках снимки канала применяются к **предпросмотровому** конфигу
  (`_previewConfig`), а не к сохранённому.
- Оверлей по-прежнему не перескакивает и не позиционируется заново — только перерисовывается
  содержимое с текущими настройками.
- После закрытия настроек предпросмотр сбрасывается и возвращается обычный режим
  (игра/рабочий стол).

## Из 1.2.0

- Живой предпросмотр для шрифта, высоты строки, шапки, аватаров, значков групп и цветов.
- Строки и шапка автоматически растут под шрифт — без наложения текста.
- Кнопка «Предпросмотр на рабочем столе» убрана.
- Подсказка «Ctrl+Alt + мышь» в настройках и в меню трея; пункт меню без комментария в скобках.

## Установка и обновление

- Трей → «Проверить обновления» → 1.2.1 (после установки оверлей запустится сам).
- Или вручную: `TsOverlay-1.2.1-Setup.msi`.

- Сборка без ошибок; логика `OnSnapshot` использует `_previewConfig` при `_settingsOpen`.
- Бэкап в `X:\Work` обновляется сразу после релиза (`tools\backup-to-work.ps1`).
