# TS Overlay 1.3.2

Лаконичный интерфейс без серверных групп, поддержка русского и английского языков, корректное переключение серверов в TS3 по микрофону и полная совместимость с TeamSpeak 6.

## Что изменилось

- **Интерфейс**: убраны значки серверных групп в строках участников для максимальной компактности и чистоты оверлея.
- **Мультиязычность (RU / EN)**: добавлена встроенная поддержка русского и английского языков с возможностью переключения на лету в настройках («Общие» → «Язык интерфейса») и автоопределением по языку системы.
- **Цвета и оформление**: понятные названия настроек цветов (фон оверлея, имена участников, неактивные / AFK, подсветка речи, индикатор выключенного микрофона) с поясняющими всплывающими подсказками.
- **TeamSpeak 3**: исправлено определение активного сервера при одновременном подключении к нескольким вкладкам. Оверлей теперь строго отслеживает статус включенного микрофона (`client_input_hardware`) и активность речи, переключая отображение при нажатии кнопки «Включить микрофон» на другой вкладке.
- **TeamSpeak 6**: сохранена полная обратная совместимость Remote Apps идентификатора (`lv.aliennation.tsoverlay`), благодаря чему обновление проходит бесшовно без необходимости повторно выдавать разрешения или подтверждать доступ.
- **Новые пользователи TS6**: добавлено всплывающее уведомление в трее при первом запуске с подсказкой подтвердить доступ в настройках TeamSpeak 6.

## Установка и обновление

- Трей → «Проверить обновления» → 1.3.2 (после установки оверлей запустится сам).
- Или вручную: `TsOverlay-1.3.2-Setup.msi`.
