# TS Overlay

Оверлей TeamSpeak для Windows: показывает, кто находится в вашем канале, подсвечивает говорящих
и помечает тех, у кого выключен микрофон или звук. Работает с **TeamSpeak 3** и **TeamSpeak 6**
одновременно (выбирается запущенный клиент), живёт в трее и появляется только поверх выбранных игр.

**Скачать:** [последний релиз](../../releases/latest) · `TsOverlay.exe` + самодостаточная сборка.
Нужен Windows 10/11 x64; для облегчённой версии — [.NET 8 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0).

## Что умеет

- Список всех участников **вашего текущего канала** (ник, «говорит», микрофон выключен, звук выключен, отошёл).
- Подсветка говорящего: цвет строки, точка и ник.
- Запуск вместе с Windows и/или вместе с клиентом TeamSpeak; закрытие вместе с TeamSpeak.
- Трей: включить/выключить оверлей, настройки, предпросмотр на рабочем столе, запуск TeamSpeak, выход.
- Список игр: оверлей показывается только когда активна игра из списка; игры добавляются
  из запущенных процессов или выбором `.exe`.
- Настройка положения (8 углов/центров), отступов, ширины, масштаба, прозрачности, цветов и шрифта.

## Как это работает

Оверлей — **отдельное прозрачное окно поверх игры**, без внедрения в процесс игры и без хуков
DirectX/OpenGL. Клики проходят сквозь него, фокус оно не забирает.

Данные берутся из самого клиента TeamSpeak:

| Клиент | Источник данных | Что нужно |
|---|---|---|
| TeamSpeak 3 | встроенный плагин **ClientQuery** (TCP `127.0.0.1:25639`) | включённый плагин ClientQuery; ключ API подхватывается из `clientquery.ini` |
| TeamSpeak 6 | **Remote Apps** WebSocket (`ws://127.0.0.1:5899`) | один раз разрешить приложение в клиенте (Настройки → Remote Apps) |

Оба источника дают одно и то же: список клиентов, канал, флаги `input muted`/`output muted`,
события «начал/закончил говорить», перемещения по каналам.

## Ограничения

- **Эксклюзивный полноэкранный режим** (exclusive fullscreen) не поддерживается: обычное окно
  не может рисовать поверх него. Работают оконный и безрамочный полноэкранный режимы — их
  использует большинство современных игр. Для exclusive fullscreen нужен отдельный проект
  с внедрением в игру (D3D/Vulkan-хук), это осознанно не делалось: сложно, хрупко и рискованно
  с античитами.
- TeamSpeak 6 Remote Apps — API в статусе alpha: имена событий могут меняться между версиями клиента.
- Оверлей показывает текущий канал **своего** клиента; если переключить вкладку сервера в TS6,
  приложение переподключится и покажет состояние активной вкладки.

## Сборка

Нужен .NET 8 SDK.

```powershell
dotnet build .\src\TsOverlay\TsOverlay.csproj -c Release
```

Готовый exe: `src\TsOverlay\bin\Release\net8.0-windows\TsOverlay.exe`.

Публикация одним файлом (требуется установленный .NET 8 Desktop Runtime):

```powershell
dotnet publish .\src\TsOverlay\TsOverlay.csproj -c Release -r win-x64 --self-contained false `
  -p:PublishSingleFile=true -o .\dist
```

Самодостаточная сборка (ничего дополнительно ставить не нужно, ~150 МБ):

```powershell
dotnet publish .\src\TsOverlay\TsOverlay.csproj -c Release -r win-x64 --self-contained true `
  -p:PublishSingleFile=true -o .\dist-standalone
```

## Первый запуск

1. Запустите `TsOverlay.exe` — появится иконка в трее, откроется окно настроек.
2. **TeamSpeak 3**: убедитесь, что в клиенте включён плагин ClientQuery (Настройки → Плагины).
   Ключ обычно подхватывается сам; если нет — вкладка «Подключение» → «Взять из ini».
3. **TeamSpeak 6**: подключитесь к серверу, затем в клиенте откройте Настройки → Remote Apps
   и разрешите приложение «TS Overlay» (запрос появляется при первом подключении оверлея).
4. Вкладка «Игры» → «Добавить из запущенных…» — выберите игру (или укажите `.exe`).
5. Сверните TeamSpeak и запустите игру: в выбранном углу появится панель с составом канала.

Настройки хранятся в `%APPDATA%\TsOverlay\config.json`, ключи API шифруются DPAPI.
Журнал: `%APPDATA%\TsOverlay\overlay.log`.

## Диагностика

Если оверлей пустой, проверьте источник данных отдельно от интерфейса:

```powershell
# TeamSpeak 3
.\TsOverlay.exe --probe ts3 --probe-seconds 15
# TeamSpeak 6 (в клиенте нужно разрешить приложение)
.\TsOverlay.exe --probe ts6 --probe-seconds 20
```

Результат пишется в `%APPDATA%\TsOverlay\probe.log`: состояние подключения, канал, участники
и их флаги. Окно настроек можно открыть без трея: `TsOverlay.exe --settings`.

## Структура проекта

```
src/TsOverlay/
  App.xaml(.cs)             — точка входа, единственный экземпляр, режимы --probe/--settings
  AppHost.cs                — связка: конфиг, монитор TS, игры, оверлей, трей
  Models/                   — снимок состояния TS, настройки, профили игр
  Services/
    Ts3ClientQuerySource.cs — провайдер TeamSpeak 3 (TCP ClientQuery)
    Ts6RemoteAppSource.cs   — провайдер TeamSpeak 6/5 (WebSocket Remote Apps)
    TeamSpeakMonitor.cs     — определяет запущенный клиент, держит подключение
    GameWatcher.cs          — активное окно игры, DPI, прямоугольник
    Native.cs               — Win32-интероп: окна, DPI, прозрачность, topmost
    ConfigService.cs        — JSON-конфиг + DPAPI
    TrayService.cs          — иконка и меню в трее
    Probe.cs                — диагностический режим
  ViewModels/               — строки клиентов и состояние панели
  Views/
    OverlayWindow.xaml      — прозрачное окно оверлея
    SettingsWindow.xaml     — настройки
    RunningAppsWindow.xaml  — выбор игры из запущенных процессов
```

## Идеи развития

- Внедрение в игру (D3D11/12, Vulkan) для exclusive fullscreen.
- Аватары и значки серверных групп, как в клиенте.
- Горячие клавиши: показать/скрыть оверлей, «кто говорит» поверх любого окна.
- ServerQuery как резервный источник (не требует плагина, но нужны права на сервере).
- Автообновление и установщик.
